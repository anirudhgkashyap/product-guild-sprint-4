Add this to api/main.py, right after `app = FastAPI(...)` and before the
routers/routes are defined. Without it, any browser call to /api/* from
a different origin than the API itself (a different Vercel deployment,
a local dev server, opening the frontend from file://, etc.) gets
silently blocked by the browser before your route code ever runs.

--------------------------------------------------------------------
from fastapi.middleware.cors import CORSMiddleware

app = FastAPI(title="Contract Negotiation Platform API")

app.add_middleware(
    CORSMiddleware,
    allow_origins=[
        "http://localhost:5500",          # local static server, if you use one
        "https://your-frontend.vercel.app",  # replace with your real frontend URL
    ],
    allow_credentials=True,
    allow_methods=["*"],
    allow_headers=["*"],
)

app.include_router(auth_router)
--------------------------------------------------------------------

Notes:
- If frontend and backend are deployed from the SAME Vercel project
  (frontend as static files, api/* as the functions — the setup
  vercel.json already implies), everything is same-origin and you
  don't need this at all. Add it only if you're serving the frontend
  from somewhere else.
- allow_origins=["*"] is fine while testing locally, but tighten it to
  your real frontend URL(s) before this goes anywhere near production
  — wildcard + allow_credentials=True is a combination browsers/
  security scanners will flag.
